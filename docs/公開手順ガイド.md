# ホームページ公開までのご案内（kukuna-lino.com）

## 結論：追加契約はおそらく不要です

いま契約中の **ロリポップ！** が「レンタルサーバー」のプラン（エコノミー／ライト／スタンダード等）であれば、
メールだけでなく **ホームページの公開もそのまま可能** です。今回のサイトはHTMLだけで動く構成（WordPress不要）にしているため、最も安いプランでも公開できます。

> 契約内容のキャプチャを拝見して、プラン名を確認させてください。
> 「ロリポップ！レンタルサーバー ○○プラン」と表示されていれば追加契約は不要です。

## 公開までの流れ

| # | 作業 | 担当 |
|---|---|---|
| 1 | ロリポップ管理画面で、契約プラン名を確認しキャプチャを共有 | お客様 |
| 2 | 管理画面「サーバーの管理・設定 → 独自ドメイン設定」で `kukuna-lino.com` の **公開（アップロード）フォルダ** を確認・設定 | お客様 or 制作側 |
| 3 | 「セキュリティ → 独自SSL証明書導入」で `kukuna-lino.com` と `www.kukuna-lino.com` に **無料SSL** を設定（https化） | お客様 or 制作側 |
| 4 | 制作したファイル一式を公開フォルダへアップロード（管理画面の「ロリポップ！FTP」で可能）<br>アップロードするもの：`index.html` `philosophy.html` `business.html` `company.html` `contact.html` `assets` フォルダ<br>（`docs`・`tools` フォルダは不要） | 制作側 |
| 5 | `https://kukuna-lino.com/` で表示確認 | 双方 |

※ 手順2〜4は、ロリポップのユーザー専用ページのログイン情報（またはFTP情報）をご共有いただければ、こちらで代行できます。

## ご注意いただきたい点

- **メールへの影響はありません。** すでにメールが使えている場合、ドメインはロリポップに向いているため、ホームページを置いてもメール設定はそのままです。
- **お名前.comの更新を忘れずに。** ドメインの自動更新が有効になっているかご確認ください（期限切れになるとメール・サイトともに止まります）。
- **ECショップ用のサブドメイン**（`mugensui.kukuna-lino.com`）は、ショップ側のサービス（Studio／Shopify等）の案内に従い、DNS設定を追加します。メインサイトとは別に設定するため干渉しません。

## もし「メール専用サービス」だった場合

ロリポップの管理画面からレンタルサーバープランへ変更・追加いただくのが最も簡単です（今回のサイトであれば最安プランで十分です）。
別の選択肢として Studio で公開する方法もありますが、独自ドメインの利用に有料プランが必要で、DNS設定もやや複雑になるため、今回はロリポップでの公開をおすすめします。
